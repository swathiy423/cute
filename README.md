# POWER

A browser-based webcam experiment that lets you control visual effects using hand gestures. Switch between different powers using your keyboard and interact with the effects through your webcam.

## Live Demo

**Run POWER directly in your browser:**  
https://cute-woad-rho.vercel.app/

No installation is required. Simply open the link and allow webcam access.

## How to Use

1. Open the [live demo](https://cute-woad-rho.vercel.app/) in your browser.
2. Allow access to your webcam when prompted.
3. Show your hands to the camera.
4. Use the number keys to switch between different powers.
5. Experiment with the hand-controlled effects.

## Controls

Use the following number keys to switch between powers:

### 1 — Fire & Ice

- Left hand controls Fire.
- Right hand controls Ice.
- Painting with this power starts after a 10-second delay.

### 2 — Lightning

Use your hand movements to trigger and control lightning effects.

### 3 — Red & Blue

- Left hand controls Red.
- Right hand controls Blue.
- Painting is not available with this power.

## Development Note

This project was built as a small experimental project using a vibecoding approach. I originally planned to include stronger glow effects, but removed them because they caused noticeable performance issues. The final version focuses on keeping the interactions responsive and the experience smooth.

## Run Locally

If you want to run the project locally, clone the repository and open `index.html` through a local development server.

```bash
git clone <repository-url>
cd POWER
```

Then start the project using a local server and open it in your browser.
